About

Built with vanilla JavaScript and Web Components, this collection follows a zero-dependency approach. Each tool is encapsulated using the Shadow DOM for style isolation, with responsive layouts powered by CSS Grid and Flexbox. Theming uses CSS custom properties, while modern APIs like localStorage and the Clipboard API handle state and interactions.

No frameworks, no build tools, no servers, no tracking. Just native browser APIs doing what they do best. Everything runs client-side, with progressive enhancement ensuring core functionality works everywhere.
